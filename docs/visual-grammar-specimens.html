상자를 걷어낸 그림 열 가지

AI Agent 시리즈의 미들웨어 그림 두 개(모델 호출 제한, 개인정보 가리기)를 상자 없이 다시 그렸다. 내용은 그대로 두고 그리는 방식만 바꿨다. 오른쪽 그림은 모두 눌러 볼 수 있다.

  • 모든 것이 둥근 테두리 상자 — 말도, 미들웨어도, 결과도 같은 모양
  • 뜻 없는 색 배정 — 파랑·초록·주황이 상태가 아니라 순번
  • 상자 → 화살표 → 상자 세로 쌓기 — 어떤 개념이든 같은 뼈대
  • 상자 안 "제목 + 회색 부제" 두 줄 — 템플릿 카드의 문법
  • 장식 아이콘 — ⚙ 하나가 아무것도 설명하지 않음
01 · 원문에 직접 표시하기

말 자체가 그림이다

바뀌는 것이 문장 속 한 토막이면 문장을 상자에 넣지 말고 그 토막에 직접 표시한다. 검열 문서의 검은 줄, 교정지의 빨간 펜처럼 독자가 이미 아는 표기를 빌린다.

레퍼런스
NYT 뮬러 보고서 검열 표시, Genius 가사 주석
맞는 개념
입력이 변환되는 것: 마스킹·토큰화·프롬프트 템플릿 치환
strategy=

내 이메일은 [REDACTED_EMAIL] 이고 티켓 상태 알려줘

통째로 이름표로 바꿈. 모델은 주소를 모른다

모델이 실제로 받는 문장만 보여 준다. "사용자가 보낸 말 / 모델이 받는 말" 두 상자 대신, 같은 문장 한 줄이 제자리에서 바뀐다.

02 · 실물 은유

호출권에 구멍을 뚫는다

제한·할당량은 눈에 익은 물건으로 바꾸면 설명이 필요 없다. 표에 구멍이 다 뚫리면 개찰구가 닫힌다. 숫자 2를 "남은 칸 두 개"로 보이게 한다.

레퍼런스
Bartosz Ciechanowski, Mechanical Watch, Nicky Case, The Evolution of Trust
맞는 개념
rate limit, 토큰 예산, 재시도 횟수, 컨텍스트 창 크기
2

버튼을 누를 때마다 모델을 한 번 부른다. 칸이 남아 있으면 구멍을 뚫고 지나간다.

03 · 눈금 한 줄

시간축 하나에 자르는 선 하나

순서가 핵심이면 상자를 세로로 쌓지 말고 수평선 위 눈금으로 찍는다. 잉크를 거의 안 쓰고, 두 제한(run·thread)이 어디서 겹쳐 끊기는지까지 한 줄에 들어간다.

레퍼런스
Edward Tufte, Beautiful Evidence의 스파크라인, Gapminder 시간축
맞는 개념
루프 횟수, 재시도, 스트리밍 토큰, 요청 타임라인
2 3

한 대화에서 질문을 두 번 했고, 매번 모델이 세 번 부르려 한다. 검은 눈금은 나간 호출, 빈 눈금은 막혀서 못 간 호출이다.

04 · 로그가 곧 그림

대화 기록에 줄을 긋는다

개발자 독자는 로그를 읽을 줄 안다. 실제로 오간 메시지를 그대로 놓고, 막힌 지점에 빨간 줄과 손글씨 한 줄만 더한다. 그림이 실제 실행 결과와 똑같아서 믿음이 간다.

레퍼런스
Julia Evans 진(zine)의 터미널 주석, Stripe API 문서 요청·응답 나란히
맞는 개념
에이전트 루프, 도구 호출, 프롬프트 인젝션이 끼어드는 지점
user티켓 #4821 지금 어떻게 됐어? model1get_ticket(4821) 부를게 tool{"status": "대기", "updated": "10-18"} model2get_history(4821) 도 볼게 tool[3건] model3get_assignee(4821) 도…run_limit=2, 여기서 안 나간다 aiModel call limits exceeded: run limit (2/2)exit_behavior="end" 면 이 한 줄이 마지막 답

번호 뱃지는 모델 호출에만 붙는다. 도구 실행은 세지 않는다는 것이 따로 설명 없이 보인다.

05 · 생명선

세로줄 세 개와 오가는 말

누가 누구에게 무엇을 넘기는지가 핵심이면 참여자를 세로 실선으로만 둔다. 상자는 없고, 화살표 위에 실제로 넘어가는 문장을 쓴다. block 은 화살표 방향이 거꾸로 바뀌는 것으로 차이가 보인다.

맞는 개념
MCP 주고받기, OAuth, 미들웨어 전후, 스트리밍 응답

06 · 작은 그림 여러 장

네 결과를 한눈에 줄 세우기

토글로 하나씩 보여 주면 앞의 것을 기억해야 비교된다. 같은 문장을 같은 크기로 네 줄 놓고 다른 부분만 다르게 칠한다. 눈이 세로로 훑으면서 차이만 잡는다.

레퍼런스
Edward Tufte, Envisioning Information의 small multiples, The Pudding
맞는 개념
옵션 비교, 양자화 단계, temperature 값별 출력

mask·hash 값은 모양을 보여 주려고 만든 예시다.

07 · 손그림

양파 껍질처럼 감싼 미들웨어

반듯한 선과 균일한 둥근 모서리가 자동 생성 티의 큰 몫이다. 같은 구조라도 흔들리는 선과 손글씨로 그리면 화이트보드 앞에서 설명하는 느낌이 난다. 미들웨어가 모델을 겹겹이 감싼다는 구조도 층으로 보인다.

레퍼런스
Excalidraw, Maggie Appleton 손그림 설명, Rough.js
맞는 개념
계층·감싸기 구조: 미들웨어, 하네스, 샌드박스
누를 때마다 선이 조금씩 다르게 흔들린다
08 · 노선도

미들웨어는 어느 역에 서나

루프와 갈고리(hook)가 섞인 흐름은 지하철 노선도가 잘 푼다. 큰 역은 모델·도구, 작은 환승역은 before_model 같은 hook 이다. 미들웨어마다 노선 색을 주면 어디서 끼어드는지가 갈아타는 역으로 보인다.

레퍼런스
Harry Beck 런던 지하철 노선도, Transit Maps
맞는 개념
에이전트 루프의 hook, CI 파이프라인, 요청 생명주기

검은 선이 에이전트 본선이다. 색 선은 미들웨어가 지나가는 역만 잇는다.

09 · 흐르는 글자

체에 걸리는 글자들

미들웨어를 "처리하는 상자"가 아니라 말이 지나가는 체로 그린다. 글자가 한 자씩 체를 통과하고, 이메일 글자만 걸려 이름표로 바뀐다. 스트리밍으로 흘러간다는 성질도 같이 보인다.

레퍼런스
Red Blob Games, Ciechanowski, Internet의 패킷 흐름
맞는 개념
토큰 스트리밍, 필터·가드레일, 토크나이저
들어온 말
모델로 나간 말
