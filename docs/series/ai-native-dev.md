# AI 네이티브 개발 입문 시리즈 계획 — 전면 재생산 (2026-10-14)

`/study docs/series/ai-native-dev.md N편` 으로 한 편씩 만든다. 이 문서가 시리즈의 원본이다.

- **왜 다시 만드나 (2026-10-14 사용자 지시):** 11편 모두 `/study` 규약 이전(2026-09-16)에 마크다운으로 만든 글이다.
  **주제만 가져오고** 내용은 다시 조사해서 HTML 학습 페이지로 새로 쓴다. 옛 글의 문장·구성은 옮기지 않는다.
  옛 글의 이미지(공식 문서·조사 보고서 캡처)는 그림을 대신하지 않는 범위에서 다시 써도 된다.
- **series 슬러그:** `ai-native-dev`. 슬러그는 옛 글 그대로(링크 보존), 원고를 `.md` → `.html` 로.
- **독자:** 코딩 에이전트를 처음 접하는 사람(`POSTING.md` 5-0 중학생 눈높이). 프로그래밍을 해 봤다고 가정하지 않는다 —
  "PR", "테스트", "린터" 도 처음 나올 때 푼다. 설정 파일·명령 예시는 5-7 형식으로 짧게.
- **수치는 쓰기 직전에 다시 확인한다.** 이 시리즈는 조사 보고서(Stack Overflow·DORA·METR·LinearB 등) 숫자가 많고 빨리 낡는다.
  옛 글의 숫자를 그대로 옮기지 않고 원문으로 확인한 것만 쓴다.
- **겹치는 글:** AI Agent 시리즈(`docs/series/ai-agent.md`) 20~22편(MCP)·24편(보안)과 주제가 닿는다. 이 시리즈는
  "코딩 에이전트를 쓰는 개발자" 관점이고, AI Agent 시리즈는 "Agent 를 만드는 개발자" 관점이다.
