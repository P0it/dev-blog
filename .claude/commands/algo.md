# /algo — 알고리즘 학습 페이지 만들기

개념 하나를 받아 `src/app/algo/<slug>/page.tsx` 를 쓴다.
설계는 `docs/superpowers/specs/2026-10-17-algo-visualizer-design.md`, 기준 페이지는
`src/app/algo/binary-search/page.tsx` 다. **먼저 기준 페이지를 열어 본다.**

이 탭은 Supabase 를 쓰지 않는다. 어드민도 적재 스크립트도 없다. 전부 레포 안 TSX 다.

## 입력

`/algo 투 포인터` 처럼 개념 이름, 또는 `registry.ts` 의 slug.

## 절차

1. **`src/content/algo/registry.ts` 에서 그 항목을 찾는다.** 없으면 어느 카테고리에 넣을지
   정해 추가한다. `title`(알고리즘 이름)과 `lede`(독자가 아는 장면)를 확정한다.
2. **스텝 테이프를 만든다** — `src/lib/algo/<slug>.ts`.
   - 보여 줄 Python 코드를 `<NAME>_CODE` 배열로 먼저 적고, 제너레이터가 그 줄 번호를 따라간다
   - 테스트를 **먼저** 쓴다(`<slug>.test.ts`). 빈 입력·길이 1·못 찾는 경우를 넣는다
   - `scripts/algo/trace_<slug>.py` 로 실제 Python 을 돌려 fixture 를 만들고 스텝 단위로 대조한다.
     fixture 는 커밋한다 — CI 에 Python 을 들이지 않는다
3. **페이지를 쓴다** — 사양 3절 ①~⑦ 순서를 지킨다.

| | 자리 | 비고 |
|---|---|---|
| ① | 직접 해 보기 | 독자가 하는 것. **알고리즘 용어 금지.** 타이핑 요구 금지 |
| ② | 되짚기 | ①의 결과를 숫자로 보이고 **여기서 처음** 이름을 붙인다 |
| ③ | 조건 짚기 | 규칙으로 주지 않고 ①에서 끌어낸다 |
| ④ | 코드와 플레이어 | `TrackPlayer` 또는 `GridPlayer`. 격자는 `layout="stack"` |
| ⑤ | 확인 문제 | **오답은 같은 알고리즘이 다른 입력에서 실제로 하는 행동**으로 |
| ⑥ | 틀리는 자리 | 경계 조건, 파이썬 함정(재귀 깊이, `list.pop(0)`) |
| ⑦ | 꺼내라는 신호 | 칩 3개. 코딩테스트에서 이걸 고르는 근거 |

②와 ⑦이 비면 올리지 않는다.

4. **registry 의 `status` 를 `ready` 로 바꾼다.** 페이지 파일이 없으면 테스트가 막는다.
5. **`npm test` 와 `npx tsc --noEmit` 를 돌린다.** 화면은 `npm run dev` 로 직접 눌러 본다.
6. **`humanize` 로 본문을 윤문한다**(`POSTING.md` 2-4). 코드와 변수 이름은 건드리지 않는다.

## 글 규칙

- **줄글 금지.** 문단 셋이 될 자리는 키워드 머리 불릿 셋으로. 수가 이어지면 체인(`100 → 50 → …`),
  정의는 등호(`매번 절반씩 버리는 방법 = 이분 탐색`)
- **한 문장은 한 가지만.** `~때문입니다`로 원인과 결과를 겹치지 않는다
- **한 문단은 세 문장을 넘지 않는다**
- **아침에 머리가 안 깬 상태로 읽어도 후루룩** — 집중해야 이해되면 실패다
- **출퇴근길 모바일이 기본** — 한 쪽은 3~5분, 조작은 44px 이상, 가로 스크롤 금지
- 제목은 알고리즘 이름, 소제목은 독자가 아는 장면

## 쓰는 부품

| | |
|---|---|
| `TrackPlayer` | 배열 한 줄. 정렬처럼 값이 움직이면 스텝의 `stage.values` 를 쓴다 |
| `GridPlayer` | 격자 + 큐. `layout="stack"` 이라 코드가 아래로 간다 |
| `Quiz` | 어느 쪽을 골라도 이유가 열린다. 정답은 정확히 하나 |
| `Counter` | 두 방법의 연산 횟수를 나란히 |
| `GameReveal` `SortReveal` `SpreadReveal` | ① 해 보기 → ② 되짚기. 끝내기 전에는 뒤가 숨는다 |
| `josa(n, "이", "가")` | 숫자 뒤 조사. 문자열을 그냥 이으면 `31 가` 가 된다 |

**서버 컴포넌트에서 클라이언트 컴포넌트로 함수를 넘길 수 없다.** 무대를 고르는 일은
`TrackPlayer`·`GridPlayer` 같은 클라이언트 래퍼가 맡는다. 되짚기 문단의 숫자도
`*Reveal` 이 직접 찍는다.
