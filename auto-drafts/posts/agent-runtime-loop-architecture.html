모델은 도구를 실행하지 않는데
Agent는 어떻게 일을 끝낼까요?

모델은 다음에 할 행동을 말할 뿐입니다. 도구를 실행하고 결과를 기록하며 멈출 때를 정하는 일은 런타임이 맡습니다.

같은 요청을 실제 구성 요소 이름으로 다시 그리면 아래 흐름도가 됩니다. 비서가 하던 일은 에이전트 루프와 도구 실행기가 나눠 맡고, 일지는 메시지 기록입니다.

이 글의 용어 · 위 장면에서 부른 이름

Agent 런타임비서
모델과 도구 사이를 오가며 실제로 실행하고 기록하는 우리 코드
모델자문실의 전문가
다음에 할 일만 답하는 AI. 앞의 일을 기억하지 못해 매번 기록 전체를 다시 읽는다
메시지 기록일지
지금까지 주고받은 요청과 답, 도구 결과를 순서대로 적은 목록
도구 목록책상 뒤 판
모델이 고를 수 있는 기능의 이름과 넣어야 할 값을 적어 보내는 목록
턴자문실에 한 번 다녀오기
모델에게 한 번 묻고 답을 받는 한 바퀴
tool_use · end_turn전문가의 두 가지 답
"이 도구를 써라"와 "다 끝났다". 앞의 답이면 한 바퀴 더 돈다
사람 승인실행 전 확인
되돌리기 어려운 일을 하기 전에 사람에게 먼저 묻는 단계

흐름도 밖에서 런타임이 챙기는 것

모델에 보내려고 들고 있는 것

  • 지시문"팀 비서다. 여러 사람에게 보내기 전에는 확인받는다"
  • 메시지 기록턴마다 결과가 붙어 길어진다. 단기 메모리
  • 도구 목록find_free_time · create_event · send_message의 이름과 입력 형식
  • 장기 메모리"팀" = 6명, 채널은 #team

루프가 멈추는 조건

  • 답 완성end_turn · 더 부를 도구가 없다
  • 반복 한도정해 둔 횟수를 넘으면 끊는다
  • 사람 승인 대기위험한 도구 앞에서 멈췄다 이어 간다
  • 오류 · 거절도구 오류는 결과로 돌려주고 refusal이면 끝낸다
