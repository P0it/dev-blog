## 1. 세션을 지운 MCP 규격이 7월이 아니라 10월에 기본값이 됐다 ⭐ 완성 원고로 선택

**제목 후보**

- `MCP 서버에서 세션이 사라지면 무엇이 깨질까요?` ← 채택 (질문형, 검색어 MCP 가 앞, 답은 본문)
- `Claude Code 가 10월에 바꾼 MCP 기본값`
- `세션 없는 MCP 를 먼저 물어보기 시작한 쪽`

**왜 지금인가**

2026년 10월 6일 Claude Code 2.1.292 가 로컬 stdio MCP 서버 연결을 모든 설치에서 프로토콜
`2026-07-28` 로 협상하도록 기본값을 바꿨고, 10월 8일 2.1.295 가 claude.ai 커넥터까지 같은 기본값으로
옮겼습니다. 규격 자체는 7월 28일에 나왔지만 그동안 클라이언트는 옛 핸드셰이크로 붙었습니다.
서버를 만든 쪽 입장에서 실제 분기점은 규격 발표일이 아니라 클라이언트가 먼저 물어보기 시작한
이번 주입니다.

**핵심 앵글 한 문장**

MCP `2026-07-28` 규격이 Claude Code 기본값이 되면서 세션을 쓰던 서버가 무엇을 잃는지(initialize
에서 받던 클라이언트 정보, `Mcp-Session-Id`, `ping`, 채널 등록)를 공식 문서의 문장으로 하나씩
확인하고, 서버·클라이언트 양쪽에 남아 있는 탈출구를 가린다.

**글 구조 아웃라인**

- MCP 서버를 하나 만들어 붙여 둔 장면에서 출발 → 10월에 바뀐 건 내 서버가 아니라 클라이언트의
  기본값이라는 직답 → 그래서 무엇이 깨지는지
- 협상 규칙부터: Claude Code v2 런타임은 HTTP·stdio·claude.ai 커넥터 서버에 새 리비전을 지원하는지
  묻고, 지원한다고 답한 서버에만 쓴다. 나머지는 v1 그대로 붙는다 — 옮기지 않은 서버는 깨지지 않는다
- 깨지는 건 "지원한다"고 답한 순간부터다. `initialize` 가 돌지 않으니 `getClientCapabilities()` ·
  `getClientVersion()` 이 `undefined` 로 떨어지고, `Mcp-Session-Id` 가 없어 `ctx.sessionId` 에 걸어 둔
  상태가 사라지고, `ping` 은 `-32601` 로 돌아온다
- 규격 두 판을 항목별로 마크다운 표 — `initialize` / 세션 헤더 / `ping` / 필수 헤더 / 상태 보관
- 상태를 버리라는 게 아니라 옮기라는 것: `requestState` 를 서버가 돌려주고 클라이언트가 그대로
  되돌려 보낸다. 서명은 하지만 암호화는 하지 않으니 신뢰하지 않는 입력으로 다룬다
- Claude Code 문서가 적어 둔 부작용 한 줄 — 새 리비전으로 협상한 채널 서버는 채널 메시지를 전달할 수
  없어 채널로 등록되지 않는다
- 탈출구 정리로 맺는다: 클라이언트는 `MCP_PROTOCOL_NEGOTIATION=legacy` · `MCP_SDK_GENERATION=v1`,
  서버는 `legacy: 'reject'`. 그리고 SDK 쪽 기본값은 여전히 opt-in 이라는 문장

**현우 경험과 엮을 지점**

MCP 서버를 직접 만들어 Claude Code 에 붙여 쓰는 1인 개발자라면, 규격이 바뀐 날이 아니라 클라이언트
기본값이 바뀐 날에 처음 증상을 본다는 점이 이 글의 관점입니다. 세션에 상태를 얹어 둔 설계가 왜
먼저 무너지는지도 같은 축에서 읽힙니다. 체험 서술은 검토 단계에서 채웁니다.

## 2. 선거 타깃팅 금지를 풀고, 물리 하드웨어 요구사항을 새로 넣은 사용 정책

**제목 후보**

- `Anthropic 사용 정책이 11월 12일부터 새로 요구하는 것`
- `선거 타깃팅 금지를 풀면서 Anthropic 이 대신 적어 넣은 조항`

**왜 지금인가**

Anthropic 이 2026년 10월 8일 사용 정책 개정을 공개했고 시행일은 11월 12일입니다. 개인화된 투표·캠페인
타깃팅을 통째로 막던 조항이 사라지고 선거 절은 "민주적 절차를 훼손하지 말라"로 이름이 바뀌었습니다.
그 대신 Claude 가 자율적으로 물리 동작을 하는 하드웨어에 연결될 때의 요구사항이 고위험 항목으로
새로 들어왔습니다.

**핵심 앵글 한 문장**

사용 정책에서 풀린 조항(캠페인 개인화 타깃팅)과 새로 조여진 조항(물리 동작 하드웨어·무허가 추적·
기만 캠페인)을 나란히 읽어, 금지의 무게중심이 말에서 몸으로 옮겨간 지점을 짚는다.

**글 구조 아웃라인**

- 시행일 11월 12일, 그리고 martech 쪽에서 실제로 달라지는 한 줄에서 출발
- 풀린 것: 개인화 투표·캠페인 타깃팅 전면 금지 삭제. 다만 기만적 타깃팅과 데이터 오용은 다른 절에서
  여전히 금지라는 점
- 새로 조여진 것: 자율 물리 동작 하드웨어에 "관측하고 멈출 수 있는 자격 있는 운영자"와 "연결이 끊겨도
  안전 상태 유지" 요구. 무기 조항에 유도·제어 소프트웨어와 드론 무장이 명시로 들어옴
- 감시·수사 절: 동의 없는 실시간·사후 추적 금지, 수사·체포·기소 대상 판단 금지. 반대로 동의한 추적과
  콘텐츠 모더레이션·저널리즘·법률 조사는 명시 허용
- 모델을 향한 지속적 학대 금지 조항이 새로 생겼고, 집행 수단은 대화 종료라는 점
- 고위험 용도의 human-in-the-loop·고지 요구는 그대로라는 확인으로 맺는다

**현우 경험과 엮을 지점**

CSM·martech 쪽 자동화를 보는 사람에게는 캠페인 타깃팅 조항이 풀린 쪽이, AI-Native 개발 쪽에서는
하드웨어 연결 요구사항이 먼저 눈에 걸립니다. 같은 문서를 두 관점에서 읽으면 서로 다른 줄이 보이는
구조여서, 그 대비 자체가 글감이 됩니다.

## 3. 사람이 검토하지 않은 취약점 리포트를 오픈소스 메인테이너에게 보낸다

**제목 후보**

- `OSS Scanner 가 공짜로 보내 주는 리포트의 나머지 10%`
- `오픈소스 메인테이너에게 도착하는 모델이 쓴 취약점 리포트`

**왜 지금인가**

Anthropic 이 2026년 10월 8일 Cyber Mission 을 발표하면서 OSS Scanner 를 함께 열었습니다. 등록한
오픈소스 프로젝트를 주기적으로 스캔해 proof of concept 와 설명, 가능하면 수정안까지 담은 리포트를
무료로 보내는 서비스입니다. 같은 발표문이 리포트는 모델이 생성한 것이고 사람이 검토하지 않으며
참 양성률은 90% 이상을 기대한다고 적어 뒀습니다.

**핵심 앵글 한 문장**

무료로 도착하는 모델 생성 취약점 리포트에서 기대 참 양성률 90%가 메인테이너 쪽에 어떤 비용으로
떨어지는지, 그리고 Anthropic 이 그 비용을 줄이려 붙여 둔 장치(수정안 포함·펀딩·Claude for Open
Source)가 무엇인지 가린다.

**글 구조 아웃라인**

- 1인 메인테이너의 받은 편지함 장면에서 출발 → 사람이 검토하지 않은 리포트가 주기적으로 온다
- OSS Scanner 의 동작: opt-in 등록, 가장 센 모델로 주기적 스캔, 리포트 구성(PoC·설명·수정안)
- 90% 이상이라는 기대값을 메인테이너 시간으로 환산해 읽는 대목
- Cyber Mission 의 다른 축인 Critical Infrastructure Defense Program 과 창립 파트너 11곳,
  6월에 시작한 주정부 프로그램, 8월에 만든 Defender Advantage Fund 를 한 묶음으로
- 무료를 받치는 자금 구조: Python Software Foundation · Alpha-Omega · OpenSSF · Apache Software
  Foundation 등에 대한 펀딩과 Claude for Open Source 의 Max 구독 제공
- 같은 주에 확장된 Cyber Verification Program 과의 관계로 맺는다

**현우 경험과 엮을 지점**

혼자 저장소를 들고 있는 쪽에서는 리포트가 공짜로 오는 게 이득인지 부채인지가 갈립니다. 인디 개발자가
받는 자동 리포트의 처리 비용이라는 관점이 이 블로그의 축과 맞습니다.

**Sources**

- Introducing the Anthropic Cyber Mission (2026-10-08) — https://www.anthropic.com/news/anthropic-cyber-mission
- Expanding the Cyber Verification Program (2026-10-06, 관계 확인용) — https://www.anthropic.com/news/cyber-verification-program
